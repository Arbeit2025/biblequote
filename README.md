# biblequote

聖書（文語訳）の全文から、節を引いて引用できるツール。

## 機能
- トップページでランダムに1節を表示（引用文コピー付き）
- 書名一覧（旧約39書・新約27書）→ 章一覧 → 章ページ（節ごとにコピー可、前後の章への移動）
- キーワード検索（全文検索、結果は最大100件まで表示、ヒット件数を表示）
- JSON API：`/api/random`、`/api/verse?book=<書名>&chapter=<章>&verse=<節>`

## データについて
- 底本：文語訳（旧約＝明治元訳 1887／新約＝大正改訳 1917）。いずれもパブリックドメイン。
- 出典：日本語 Wikisource、補完に CrossWire JapBungo。
- 本文は文語・旧仮名遣いのまま収録している（例：創世記1:1「元始に神天地を創造たまへり」）。
- 収録範囲：全66書・1189章・31,069節スロット。

## 既知の欠落・注意点
- **イザヤ書 第1章は未収録**です（出典ページに現代訳が混在していたため、著作権上の配慮で意図的に除外）。章ページでは「この章は底本の都合により未収録です」と表示されます。
- 一部の節は空文字列です（底本の見出しが次の節に続く形になっている箇所）。章ページでは「（本文は次の節に続きます）」と表示されます。
- 15節には「[なし]」と記録されています（文語訳の底本にその節が存在しない箇所）。そのまま表示されます。
- 一部の節には、底本由来の置換文字（�）が含まれています。底本のまま収録しています。
